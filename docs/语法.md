## 第 10 页（P10）
**Super CLI**

```
super init              初始化
super run               直接运行
super build <文件.super> <输出>
                        留空为 文件.a
super tidy              整理文件结构
super version           版本
super update <--proxy>  升级
super docs <包> <函数>   查文档
super error <错误码>     查报错
super mod tidy          整理依赖
super mod map           依赖图
super file              按 SuperFile 构建
super file --makefile   把 #code-code# 部分形成 Makefile 且 File.super 删除
```
